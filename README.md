# 从逻辑门构建 CPU：Turing Complete 学习笔记

这里记录我游玩《Turing Complete》时的关卡尝试，以及对逻辑门、电路和 CPU 工作原理的学习。笔记以 Markdown 保存在这个仓库；个人网站恢复开发后，再将整理好的内容发布过去。

## 内容安排

- `levels/`：按关卡记录目标、搭建思路、遇到的问题和实际验证结果。
- `notes/`：按主题整理游戏中学到的知识，例如组合逻辑、时序电路、存储器和指令执行。
- `assets/`：存放笔记引用的截图与示意图。

这些目录会在有对应内容时建立。每篇笔记可以先记录探索过程，之后再补充结论；尚未验证的想法会明确标注。图片和笔记之间使用相对路径，方便在 GitHub 与个人网站之间迁移。

这是个人学习记录，不是《Turing Complete》的官方攻略。
